# บันทึกรายรับ-รายจ่าย (Expense Tracker)

แอปบันทึกรายรับ-รายจ่ายที่รันบน **Google Apps Script** ข้อมูลทั้งหมดเก็บใน **Google Sheets** ของคุณเอง และไฟล์แนบ (สลิป/ใบเสร็จ) เก็บใน **Google Drive** ไม่ต้องมีเซิร์ฟเวอร์และไม่มีค่าใช้จ่าย

## ฟีเจอร์

- บันทึกรายรับและรายจ่าย พร้อมหมวดหมู่ รายละเอียด และวันที่
- แนบสลิป/ใบเสร็จ (รูปหรือ PDF ไม่เกิน 8 MB) รูปจะถูกย่อก่อนอัปโหลด เปิดดูในแอปได้
- รายงานรายวัน รายเดือน รายปี: รายรับ รายจ่าย คงเหลือ กราฟเทียบรับ-จ่าย แยกตามหมวดหมู่
- เชื่อมกับ Google Sheet ที่มีอยู่แล้วได้ (วางลิงก์ในหน้า "ตั้งค่า")
- ใช้งานบนมือถือได้ (เพิ่มลงหน้าจอโฮม)

## โครงสร้างโปรเจกต์

```
src/
  Code.gs          ฝั่งเซิร์ฟเวอร์: สร้างชีต/โฟลเดอร์, อ่าน-เพิ่ม-ลบรายการ, อัปโหลดไฟล์
  Index.html       หน้าจอทั้งหมด (ฟอร์ม, รายงาน, กราฟ, ตัวดูไฟล์)
  appsscript.json  ตั้งเขตเวลา Asia/Bangkok และให้เข้าถึงได้เฉพาะเจ้าของ
.clasp.json.example  ตัวอย่างค่าตั้งต้นสำหรับ clasp
```

## ติดตั้ง: วิธีที่ 1 วางโค้ดเอง (ไม่ต้องใช้เครื่องมือเพิ่ม)

1. ไปที่ [script.google.com](https://script.google.com) แล้วสร้างโปรเจกต์ใหม่
2. วางโค้ดจาก `src/Code.gs` ลงในไฟล์ `Code.gs`
3. เพิ่มไฟล์ HTML ชื่อ `Index` แล้ววางโค้ดจาก `src/Index.html`
4. Project Settings > เปิด "Show appsscript.json manifest file" แล้ววางเนื้อหาจาก `src/appsscript.json`
5. Deploy > New deployment > Web app (Execute as: Me, Who has access: Only myself) > Deploy
6. อนุญาตสิทธิ์ครั้งแรก (ถ้ามีคำเตือน "Google hasn't verified this app" ให้กด Advanced > Go to project) แล้วเปิดลิงก์ที่ลงท้ายด้วย `/exec`

## ติดตั้ง: วิธีที่ 2 ใช้ clasp (เหมาะกับการอัปเดตจาก GitHub)

```bash
npm install            # ติดตั้ง clasp
npx clasp login        # ล็อกอิน Google (เปิด Apps Script API ที่ script.google.com/home/usersettings ก่อน)
npx clasp create --type webapp --title "บันทึกรายรับ-รายจ่าย" --rootDir src
npx clasp push         # ส่งโค้ดขึ้น Apps Script
npx clasp deploy       # สร้าง deployment ใหม่
```

ถ้ามีโปรเจกต์ Apps Script อยู่แล้ว ให้คัดลอก `.clasp.json.example` เป็น `.clasp.json` แล้วใส่ `scriptId` ของคุณ (ไฟล์ `.clasp.json` ถูกตั้งให้ไม่อัปขึ้น Git)

## การอัปเดตโค้ด

หลังแก้โค้ดต้องสร้างเวอร์ชันใหม่ของ deployment จึงจะมีผล: Deploy > Manage deployments > ไอคอนดินสอ > Version: New version > Deploy แล้วรีเฟรชหน้าเว็บ (Ctrl+Shift+R) ป้ายเวอร์ชันเล็กๆ ข้างชื่อแอปในหน้าเว็บ (เช่น v6) ใช้เช็กว่าลิงก์ที่เปิดอยู่เป็นเวอร์ชันล่าสุดหรือไม่ ควรเพิ่มเลขเมื่อแก้ `Index.html`

## ข้อมูลในชีต

ชีตชื่อ `Expenses` หนึ่งแถวต่อหนึ่งรายการ

| คอลัมน์ | ความหมาย |
| --- | --- |
| A id | รหัสรายการ (สร้างให้เอง) |
| B วันที่ | รูปแบบ yyyy-MM-dd เก็บเป็นข้อความ |
| C หมวดหมู่ | |
| D รายละเอียด | |
| E จำนวนเงิน | |
| F ไฟล์แนบ | ลิงก์ไฟล์ใน Drive |
| G บันทึกเมื่อ | เวลาที่บันทึก |
| H ประเภท | `รายรับ` หรือ `รายจ่าย` (ว่าง = รายจ่าย) |

แก้ข้อมูลในชีตตรงๆ ได้ แอปจะเห็นการเปลี่ยนแปลงเมื่อรีเฟรช

## ปรับแต่ง

- หมวดหมู่: แก้ `CATEGORIES` และ `INCOME_CATEGORIES` ที่ต้นไฟล์ `src/Code.gs`
- สี: แก้ตัวแปร CSS ใน `:root` ของ `src/Index.html` (ตอนนี้เป็นโทนฟ้า)

## ข้อควรระวังเมื่อแก้ Index.html

ระหว่างพัฒนา หน้าเว็บเคยพังด้วย `SyntaxError` เฉพาะตอนรันบน Apps Script จริง (ทดสอบนอก Apps Script ผ่านปกติ) ข้อสันนิษฐานคือสคริปต์ที่ฝังในหน้า HTML ถูก Apps Script ประมวลผลต่างจากเบราว์เซอร์ปกติ จึงมีข้อแนะนำเชิงป้องกันดังนี้

- หลีกเลี่ยงการเขียนเครื่องหมาย `//` ติดกันในข้อความของสคริปต์ (เช่นลิงก์ https ยาวๆ ในโค้ด) ให้สร้างจากข้อมูลที่ได้รับตอนรันแทน
- หลีกเลี่ยง regex ที่มีเครื่องหมาย `\`
- ถ้าเกิดข้อผิดพลาด หน้าเว็บจะแสดงข้อความ error บนการ์ดสีเข้มด้านบน ใช้เลขบรรทัดช่วยหาจุดที่พัง

## ต่อยอด

งบประมาณรายเดือนต่อหมวดหมู่, รายการประจำ (ค่าเช่า/สมาชิก), ส่งออกรายงานเป็น PDF, แชร์ชีตกับคนในครอบครัว
